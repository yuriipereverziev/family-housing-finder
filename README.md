# 🏡 Family‑Friendly Housing Finder

Інструмент для пошуку житла **з урахуванням потреб сімей з дітьми**: ціни на нерухомість, райони міста, доступність садочків, шкіл, медицини та зон відпочинку.

Проєкт орієнтований на **комфорт, безпеку та інфраструктуру для дитини**, а не просто на список оголошень.

---

## 🎯 Мета проєкту

Допомогти сімʼям швидко відповісти на питання:
- У **якому районі** краще жити з дитиною?
- **Скільки коштує житло** в цьому районі?
- Чи є поруч **садочки, школи, лікарні, парки**?

Результат — **інтерактивна карта + рейтинг районів**.

---

## 🧠 Основні можливості (MVP)

### 🏠 Нерухомість
- Середня ціна за м²
- Кількість оголошень
- Продаж / оренда

**Джерело:** DIM.RIA API

---

### 🎒 Освіта
- Садочки
- Школи (державні / приватні)
- Відстань пішки від району

**Джерело:** OpenStreetMap (Overpass API)

---

### 🏥 Медицина
- Дитячі поліклініки
- Лікарні
- Приватні клініки

**Джерело:** OpenStreetMap

---

### 🌳 Комфорт
- Парки
- Дитячі майданчики
- Зони відпочинку

---

### 🗺 OpenStreetMap (Overpass API)
Використовується для отримання:
- `amenity=school`
- `amenity=kindergarten`
- `amenity=hospital`
- `leisure=park`
- `leisure=playground`

📌 Безкоштовно
📌 Без лімітів

---

## 🧮 Рейтинг району (MVP логіка)

Кожен район отримує **індекс комфорту**:

```
Score =
  (садочки × 0.3) +
  (школи × 0.3) +
  (доступність_ціни × 0.2) +
  (парки × 0.2)
```

Усі значення нормалізуються (0–1).
